Tier 1 — Frontend (S3 Static Hosting)

Hello from S3 🚀

This static page is hosted on Amazon S3 and replicated across two AWS regions for cross-region durability.

It is the entry point of a three-tier architecture:

  • Tier 1 — Frontend: this S3 static website (cross-region replicated)
  • Tier 2 — Backend: a Python/Flask API on ECS Fargate behind an ALB
  • Tier 3 — Database: PostgreSQL on Amazon RDS (private subnets)

The backend API answers on the ALB DNS name — try /, /health, and the /items CRUD endpoints.
